## 📚 Featured Projects

###  [LQRx : InterleavedBuck](https://github.com/Natchpai/LQRx_InterleavedBuck)

**2-Phase Interleaved Synchronous Buck Converter**

**A Firmware of 2-Phase Interleaved Synchronous Buck Converter**
