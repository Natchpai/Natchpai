# Hey, I'm Natchanon Thuentham (Tonpai) 👋

I'm an Electrical Engineering student, interested in hardware and PCB design, with a focus on digital and mixed-signal circuits. </br>
This GitHub is a portfolio of my personal projects, university research, and open-source hardware designs. </br>
Feel free to explore my repositories or reach out for collaboration!
> I enjoy exploring new hardware architectures, experimenting in the real world, and improving my skills along the way.

- 🛠️ **Tools:** My computer.
- ☕ **Powered by:** Coffee
